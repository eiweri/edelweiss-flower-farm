# Информационная веб-система цветочной фермы «Эдельвейс»

Проект посвящён проектированию информационной веб-системы для оформления и обработки заказов цветочной фермы «Эдельвейс». Клиенты смогут выбирать цветы и букеты в каталоге, оформлять заказы с доставкой или самовывозом и следить за их статусом. Сотрудники фермы получат единое рабочее пространство для обработки заявок, подготовки заказов и управления ассортиментом.

## Документы проекта

В папке [docs](docs/) собраны материалы проектирования прошлого семестра: описание предметной области, требования, пользовательские сценарии, модель жизненного цикла, архитектура, UML-диаграммы и тест-кейсы.

Материалы представлены в Markdown для удобного просмотра на GitHub. Это проектная документация, реализация программного кода на данном этапе не предусмотрена.
